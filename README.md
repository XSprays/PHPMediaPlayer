## Features

- **Local Media Playback** — Upload and play local video and music files directly from your server.
- **YouTube Integration** — Stream content from a configured YouTube channel using the YouTube API.
- **View Tracking** — Track overall media views or individual video view counts.
- **Age Restriction** — Protect content behind an optional age-verification gate.
- **Admin Dashboard** — Manage media, authentication, and player settings from a centralized dashboard.
- **Responsive Design** — Designed to work seamlessly across desktop and mobile devices.
- **Customizable Settings** — Enable or disable features such as view tracking, YouTube mode, age restrictions, videos, settings, and main-site authentication.
- **Secure Authentication** — Optionally protect the main media site and administrative dashboard with password authentication.
